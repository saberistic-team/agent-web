identifying information belong here or in an organization-approved secure vault.

See [CONSENT_AND_DATA_HANDLING.md](../CONSENT_AND_DATA_HANDLING.md).

- [VALIDATION_READOUT.md](../../VALIDATION_READOUT.md)
- [templates/](../templates/) completed copies (review before commit)

```

consent-pdfs/

```
