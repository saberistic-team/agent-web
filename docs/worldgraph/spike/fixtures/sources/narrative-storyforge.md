# StoryForge Worlds

StoryForge is a branching interactive narrative platform. Each world ships with reproducible save slots and canon rules.

- **Entry:** https://example-worlds.test/narrative/storyforge/play
- **Interaction:** choice-driven scenes with AI character responses
- **Persistence:** cloud save slots versioned per release
- **AI role:** runtime dialogue and scene generation bounded by canon files
- **Creator:** StoryForge Collective

## World structure

Setting: coastal archive city. Mechanics: relationship meters and timed story beats.
