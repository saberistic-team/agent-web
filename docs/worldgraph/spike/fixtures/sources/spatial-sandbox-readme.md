# Spatial Sandbox

Open spatial world with reproducible configuration tags.

## Quick start

```bash
git clone https://github.com/example-worlds/spatial-sandbox
cd spatial-sandbox && docker compose up
```

- Entry URL: https://example-worlds.test/spatial/sandbox/run
- World type: ai_spatial
- Persistence: versioned world bundles (`world-v1.2.0`)
- AI role: procedural environment generation at build; optional runtime agent guides

## Platforms

WebGL, WebXR
