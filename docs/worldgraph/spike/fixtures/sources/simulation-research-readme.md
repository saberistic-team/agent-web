# Research Sim World

Training simulation for multi-agent coordination research.

| Field | Value |
|-------|-------|
| Entry | https://example-worlds.test/sim/research/run |
| Persistence | reproducible seed + config hash |
| AI usage | runtime agent policies |
| Rules | published in `/rules/world.md` |

Clone and run benchmarks:

```
git clone https://github.com/example-worlds/research-sim
make reproduce SEED=42
```
